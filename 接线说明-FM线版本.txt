/*
 * ===================================================
 *  🎯 项目1：温湿度显示器（F-M杜邦线版本）
 *  硬件：ESP32 + DHT11 + 0.96" OLED (SSD1306)
 *  使用F-M（母对公）杜邦线，母头直接套ESP32引脚
 * ===================================================
 *
 * 【接线说明】-- 用 F-M 线（母对公），不用面包板！
 *
 *   F-M 线：母头（有塑料壳带洞的一端）套在 ESP32 引脚上
 *          公头（金属针的一端）插面包板
 *
 *  ═══════════════════════════════════════════════
 *  步骤1：ESP32 → 面包板供电（2根 F-M 线）
 *  ═══════════════════════════════════════════════
 *
 *   线① 母头套 ESP32 "3.3V" 脚 → 公头插 面包板红色长条(+)
 *   线② 母头套 ESP32 "GND"  脚 → 公头插 面包板蓝色长条(-)
 *
 *  ═══════════════════════════════════════════════
 *  步骤2：连接信号线（3根 F-M 线）
 *  ═══════════════════════════════════════════════
 *
 *   线③ 母头套 ESP32 "D4"  脚 → 公头插 DHT11的DATA脚所在孔
 *   线④ 母头套 ESP32 "D21" 脚 → 公头插 OLED的SDA脚所在孔
 *   线⑤ 母头套 ESP32 "D22" 脚 → 公头插 OLED的SCL脚所在孔
 *
 *  ═══════════════════════════════════════════════
 *  步骤3：模块供电 —— 用 M-M 线或直接插面包板
 *  ═══════════════════════════════════════════════
 *
 *   DHT11 VCC → 面包板红色长条(+)
 *   DHT11 GND → 面包板蓝色长条(-)
 *   OLED  VCC → 面包板红色长条(+)
 *   OLED  GND → 面包板蓝色长条(-)
 *
 *  ═══════════════════════════════════════════════
 *  完整对照表
 *  ═══════════════════════════════════════════════
 *
 *  ESP32引脚   ← 母头套上 →   面包板/模块
 *  ─────────────────────────────────────
 *  3.3V           [F-M线]     面包板红色(+)
 *  GND            [F-M线]     面包板蓝色(-)
 *  D4 (GPIO4)     [F-M线]     DHT11 DATA
 *  D21 (GPIO21)   [F-M线]     OLED SDA
 *  D22 (GPIO22)   [F-M线]     OLED SCL
 *
 *  模块VCC/GND    [M-M线]     面包板红条/蓝条
 *  ─────────────────────────────────────
 *  DHT11 VCC      [M-M线]     面包板红色(+)
 *  DHT11 GND      [M-M线]     面包板蓝色(-)
 *  OLED VCC       [M-M线]     面包板红色(+)
 *  OLED GND       [M-M线]     面包板蓝色(-)
 */
