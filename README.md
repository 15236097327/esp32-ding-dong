### 安装备忘

1. VS Code 扩展搜 `PlatformIO IDE` 安装
2. 新建项目选 `Espressif ESP32 Dev Module` + `Arduino` 框架
3. 库依赖写在 `platformio.ini` 的 `lib_deps` 里
4. 代码放 `src/main.cpp`

## ✅ 已完成项目

### 1. LED 闪烁 — Hello World

```
接线：无（使用板载 LED，GPIO 2）
功能：蓝灯 0.5 秒一闪
```

**知识点：** `pinMode()` `digitalWrite()` `delay()`

---

### 2. OLED 显示屏测试

```
接线：VCC→3.3V  GND→GND  SDA→D21  SCL→D22
地址：0x3C（你的屏幕是这个地址，不是常见的 0x3D）
```

**知识点：** I2C 通信、`Adafruit_SSD1306` 库

---

### 3. 电子门铃 + 自定义表情包 🔔

```
接线：
  红外避障 VCC→3.3V  GND→GND  OUT→D4
  蜂鸣器 长脚(+)→D5  短脚(-)→GND
  OLED   VCC→3.3V  GND→GND  SDA→D21  SCL→D22

功能：
  手靠近红外 → 蜂鸣器滴滴响 + OLED 显示自定义表情包
  手拿开     → 铃铛图标 + "Waiting..."
```

**知识点：** 数字输入 `digitalRead()`、位图显示 `drawBitmap()`

---

### 4. 光控小夜灯 💡

```
接线：
  光敏电阻 VCC→3.3V  GND→GND  AO→D34
  LED 长脚(+)→220Ω电阻→D5  短脚(-)→GND

功能：
  环境暗 → LED 自动亮起 + OLED 显示 "NIGHT MODE"
  环境亮 → LED 自动熄灭 + OLED 显示 "DAY MODE"
  OLED 显示实时光照数值和亮度条
```

**知识点：** 模拟输入 `analogRead()`、阈值判断

## ❌ 失败项目 & 经验

### 温湿度显示器（DHT11 读取失败）

- `dht.begin()` 成功但 `readHumidity()` 始终返回 NaN
- 尝试了换 GPIO、换 VCC/GND 顺序、加 10kΩ 上拉电阻
- 传感器在反复尝试中发烫，疑似接反烧毁
- **教训：接线前先确认引脚定义，不确定时先拍照片确认**

## 💡 踩坑记录

| 坑 | 解决 |
|-----|------|
| Arduino IDE 装不了库/开发板 | GitHub 被墙 → 换 PlatformIO + 科学上网 |
| PlatformIO 上传失败 | 按住 BOOT 键再上传 |
| GPIO 2 接传感器导致上传失败 | GPIO 2 是启动引脚，换成 GPIO 4 或其他 |
| OLED 不显示 | 地址可能是 0x3C 或 0x3D，都试试 |
| OLED 空心孔接触不良 | 公头金属针要捅到底 |
| F-M/F-F 线选哪个 | ESP32↔模块 直连用 F-F，经过面包板用 F-M |
| 传感器发烫 | 立刻拔 USB，VCC/GND 可能接反了 |

---

## 🔧 接线习惯

1. **先断电再改接线**
2. 红=VCC/3.3V，黑=GND，其他颜色=信号
3. F-F 杜邦线直连最省事（不用面包板）
4. 多个模块共用 3.3V/GND → 用面包板红蓝条分流
5. 接完后拍照，方便排查
